## Фаза 2 — Синхронизация существующих 2-сорт (64 поз.)

Источник: `broken_2sort_to_sync.csv`

**Правило:** для каждой строки скопировать с `base_id`:

- `weight_kg` ← base (если у 2-сорта 0)
- `qty_per_cycle` ← base (если у 2-сорта 1 и у base ≠ 1)
- `mold_id` ← base (если NULL)
- `gost_mark` ← base (если пусто)

**Не менять:** `name`, `current_price`, `article` (кроме явных ошибок), `mix_*` (2-сорт в производство не идёт).

**Исключения (ручная проверка):**

| id | Причина |
|----|---------|
| 620 | Исправляется в фазе 1 |
| 609 | Неверная category — фаза 1 |
| 632 | Имя содержит «Эксперементальная 2 сорт» — аномалия, не трогать автоматически |

```sql
-- Шаблон массовой синхронизации (выполнять после просмотра CSV)
UPDATE items i2 SET
  weight_kg = g1.weight_kg,
  qty_per_cycle = g1.qty_per_cycle,
  mold_id = g1.mold_id,
  gost_mark = g1.gost_mark
FROM items g1
WHERE g1.is_deleted = false
  AND trim(g1.name) = trim(regexp_replace(i2.name, ' 2 сорт$', ''))
  AND i2.is_deleted = false
  AND i2.name ~* ' 2 сорт$'
  AND i2.id IN ( /* id из broken_2sort_to_sync.csv, кроме исключений */ );
```

## Фаза 3 — Создание недостающих 2-сорт (272 поз.)

Источник: `missing_2sort_to_create.csv`

### Правила создания (как в ERP при распалубке)

Для каждой строки 1-сорта (`base_id`):

| Поле | Значение |
|------|----------|
| `name` | `{base_name} 2 сорт` |
| `category`, `unit`, `item_type` | как у 1-сорта |
| `weight_kg`, `qty_per_cycle`, `mold_id`, `gost_mark` | как у 1-сорта |
| `mix_main_tpl`, `mix_face_tpl` | **не копировать** (2-сорт не в замес) |
| `current_price` | `round(base_price / 2, 2)` |
| `dealer_price` | `round(base_dealer / 2, 2)` |
| `article` | `{base_article}2S` или `{base_id}-2S` |
| `default_warehouse_id` | **5** (склад уценки) |
| `is_deleted` | `false` |

**Перед INSERT:** `SELECT id FROM items WHERE name = '… 2 сорт'` — пропустить дубликат.

### Порядок категорий (рекомендуется)

| Очередь | Категория | Строк в CSV |
|---------|-----------|-------------|
| 1 | Бордюры и поребрики | 57 |
| 2 | Плитка гладкая | 55 |
| 3 | Плитка гранитная | 63 |
| 4 | Плитка меланж гладкая | 50 |
| 5 | Плитка меланж гранит | 45 |
| 6 | Стеновые блоки | 2 |

```sql
-- Шаблон одной вставки
INSERT INTO items (
  name, article, category, unit, current_price, dealer_price, item_type,
  is_deleted, weight_kg, qty_per_cycle, mold_id, gost_mark, default_warehouse_id
)
SELECT
  trim(name) || ' 2 сорт',
  COALESCE(NULLIF(trim(article), ''), id::text) || '2S',
  category, unit,
  round(current_price / 2, 2),
  round(COALESCE(dealer_price, 0) / 2, 2),
  item_type, false,
  weight_kg, qty_per_cycle, mold_id, gost_mark,
  5
FROM items
WHERE id = :base_id
  AND NOT EXISTS (
    SELECT 1 FROM items x WHERE x.is_deleted = false AND x.name = trim(items.name) || ' 2 сорт'
  );
```
